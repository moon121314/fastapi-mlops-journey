# MLOps Foundation API 🚀

This repository documents my journey from Backend Engineer to MLOps Engineer. It contains the foundational backend API that will eventually serve Machine Learning models.

## 🛠️ Tech Stack
*   **Language:** Python 3.12
*   **Framework:** FastAPI
*   **Server:** Uvicorn
*   **Data Validation:** Pydantic

## ✨ Current Features
*   **Health Check:** A basic `GET` endpoint to verify the server is running.
*   **Dynamic Routing:** A `GET` endpoint that takes a user's name via Path Parameters.
*   **Mock ML Prediction:** A `POST` endpoint that accepts JSON data (simulating house features) and returns a calculated prediction.
